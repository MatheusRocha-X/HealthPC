HealthPC: uma ferramenta desktop em Python para análise e limpeza segura de arquivos temporários no Windows

Texto da publicação:

Desenvolvi o HealthPC pensando principalmente em praticidade.

Queria uma forma mais simples de analisar e limpar arquivos temporários, caches e logs do Windows sem precisar fazer tudo manualmente, navegando por várias pastas do sistema ou dependendo de várias ferramentas separadas.

Então criei uma aplicação desktop que centraliza esse processo em uma interface única, com foco em rapidez de uso, visualização do que será removido e mais controle antes de executar a limpeza.

O app foi construído em Python, com interface desktop baseada em `pywebview`, usando HTML, CSS e JavaScript no frontend e um backend Python responsável pela descoberta dos alvos, análise dos arquivos, remoção controlada e persistência das configurações.

Como ele funciona na prática:
- Descobre automaticamente locais relevantes do Windows, como temporários do usuário, temporários do sistema, cache de navegador, cache de GPU/DirectX, logs antigos, Prefetch, Lixeira e cache do Windows Update.
- Faz uma análise prévia dos arquivos elegíveis antes da remoção.
- Agrupa os resultados por categoria para mostrar o que está ocupando espaço.
- Permite escolher exatamente quais locais entram na rotina de limpeza.
- Protege arquivos recentes por padrão para reduzir o risco de exclusões indevidas.
- Ignora links simbólicos e junctions para evitar sair das pastas previstas.
- Remove arquivos e tenta apagar diretórios vazios ao final do processo.
- Permite agendamento automático no Windows via `schtasks`.

Do ponto de vista técnico, aproveitei o projeto para trabalhar alguns pontos importantes:
- Backend modularizado em Python, separando interface, regras da aplicação e motor de limpeza.
- Uso de `pathlib`, validação de caminhos e checagens de segurança para manter a limpeza restrita aos diretórios autorizados.
- Execução da análise e da limpeza em threads separadas para manter a interface responsiva.
- Comunicação entre frontend e backend via API do `pywebview`.
- Persistência local de histórico e configurações em JSON.
- Empacotamento com `PyInstaller`, incluindo os assets da interface no executável final.
- Tratamento de erros para arquivos em uso, falta de permissão e pastas indisponíveis.

O que mais gostei nesse projeto foi justamente unir praticidade com cuidado técnico: não é só “apagar arquivos”, mas fazer isso de forma previsível, com revisão antes da remoção e com uma experiência simples para o usuário.
